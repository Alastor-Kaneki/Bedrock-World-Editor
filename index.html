          BEDROCK WEB EDITOR • v0.3.2 ALPHA
          
What this build actually supports

          
This is a static application: HTML, CSS and JavaScript only. It can be hosted from a normal GitHub Pages repository with no server, database, account system, or build step.

          
Live site: alastor-kaneki.github.io/Bedrock-World-Editor/

          
Build: v0.3.2-alpha • Firefox/cache recovery release

          
    
            
  • Open and re-export complete .mcworld / ZIP archives and Bedrock world folders.
    • 
            
  • Treat level.dat as the primary file: load it first, edit it directly, preserve unknown tags, and write it back into the whole-world export.
    • 
            
  • Parse and write Bedrock's 8-byte level.dat header and little-endian NBT.
    • 
            
  • Edit common world settings while preserving unrecognized NBT tags.
    • 
            
  • Edit inventory/armor/offhand from embedded NBT, raw NBT, or a recoverable LevelDB ~local_player record.
    • 
            
  • Browse the current official Bedrock item listing, including technical, Education, deprecated, hidden, and normally unobtainable IDs.
    • 
            
  • Display matching vanilla item/block sprites directly from Mojang’s official bedrock-samples repository.
    • 
            
  • Add, remove, and edit enchantments, including arbitrary numeric enchantment IDs and out-of-range levels.
    • 
            
  • Read standard LevelDB WAL records and exact keys from supported SST blocks.
    • 
            
  • Export local-player edits as a new LevelDB recovery WAL overlay without rewriting existing SST tables.
    • 
            
  • Undo/redo changes made through the editor.
    • 
          

          
Still experimental / not yet supported

          
Remote player_* selection, arbitrary chunk/subchunk editing, block entities/containers, actor editing, and complete table compaction. Unsupported table compression is skipped with a diagnostic instead of being overwritten.
